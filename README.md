# 健身记录页面

这是一个适合新手练习的静态网页示例。页面包含一个健身记录表单，可以输入：

- 训练日期
- 训练时长（分钟）
- 动作名称（例如：深蹲）
- 组数
- 每组重量（公斤）

提交表单后，记录会显示在页面下方的表格中。

## 下一步怎么操作

如果你是第一次做网页，可以按下面 3 步来：

1. 这个项目文件夹叫 `111`，当前路径是 `/workspace/111`。
2. 进入这个文件夹后，双击打开里面的 `index.html`，它会在浏览器里显示健身记录页面。
3. 在页面里填写训练信息，然后点击“保存记录”，记录就会出现在下面的表格里。

## 项目在哪里

在当前环境里，项目位置是：`/workspace/111`。项目文件夹名字是：`111`。

你真正要打开的页面文件是：`/workspace/111/index.html`。

## 如果你想自己改页面

- 想改页面上的文字：打开 `index.html`。
- 想改颜色、大小、间距：打开 `styles.css`。
- 想改“点击保存后发生什么”：打开 `script.js`。

改完后，刷新浏览器页面就能看到新效果。

## 注意

当前版本不需要安装任何软件，也不需要启动服务器。记录只会暂时显示在当前页面里，刷新页面后会消失。
